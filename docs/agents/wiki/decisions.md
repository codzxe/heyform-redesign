# Decisions

Dated record of maintainer decisions. Newer entries supersede older ones; nothing is rewritten.

- **2026-11-06 — Upstash Redis replaces Bull/ioredis.** The maintainer requires Upstash Redis, not Bull. All queue, session, cache, lock and throttle Redis usage migrates (spec #2, tickets #12–#15). Implementation choice by agents: queue client interface with Upstash REST implementation for production (`UPSTASH_REDIS_REST_URL`/`UPSTASH_REDIS_REST_TOKEN`) and an ioredis implementation for local dev/test against docker Redis, so e2e stays hermetic.
- **2026-11-06 — Layout is upgraded; palette and fonts are NOT.** Maintainer: "design is good and color and font is good but layout is bad." `--hf-*` token values, Inter + Playfair Display and the Tailwind palette must not change; only structure/density/containers/navigation/states (spec #5, tickets #33–#37). L-tickets carry a guard criterion that the token block diff stays empty.
- **2026-11-06 — Monorepo shape accepted as-is.** The requested `apps/`+`packages/` restructure is satisfied by the existing pnpm workspace (`packages/server|webapp|form-renderer|embed|utils|shared-types-enums|answer-utils`) — "adapt the structure to the existing stack" per the production-readiness spec. No big-bang restructure ticket; separation improves incrementally (worker split is ticket #15).
- **2026-11-06 — Platform billing provider: Stripe Billing** behind an adapter (Stripe already a dependency; spec #3, tickets #16–#18). **Respondent payments: Razorpay added beside Stripe Connect** for UPI/regional methods (ticket #40). Adapter keeps a second platform provider possible.
- **2026-11-06 — Issues are the memory.** All requirements live as GitHub issues (specs #1–#6, tickets #7–#49, epic #50) rather than chat history. Agents work ticket-by-ticket; the epic's frontier list defines what is startable.
- **2026-11-06 — Multi-agent execution model.** One ticket = one branch = one PR; agents work in git worktrees to avoid tree contention (see [implementation-plan.md](./implementation-plan.md)).
- **2026-11-06 — Repo rename suggested, not executed.** Repo is still `codzxe/heyform-redesign` while docs reference nonexistent `codzxe/myform` (broken changelog URL among others). Renaming to `myform` is a maintainer decision; ticket #9 fixes links to the real slug meanwhile. GitHub redirects would keep old URLs working if renamed.
